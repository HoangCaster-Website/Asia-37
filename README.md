# Asia-37

Website für das Asia37 Restaurant & Sushi Bar in Wiesmoor.

## Lokal starten

Im Projektordner `python3 -m http.server 8000` ausführen und [localhost:8000](http://localhost:8000/) öffnen. Die Landingpage mit Speisekarte liegt in `index.html`. Bestehende Links zu `menu.html` führen weiterhin zur passenden Rubrik. GitHub Pages kann direkt aus `main` und `/ (root)` veröffentlichen.

## Speisekarte pflegen

Die Rubriken und Einträge stehen im Abschnitt `#speisekarte` von `index.html`. Die Suche liest die Namen, Nummern und Beschreibungen aus dem HTML. Adresse, Öffnungszeiten, Telefonnummern und Buffetpreise stammen aus der Word-Vorlage.

Die Vorlage enthält Getränke, Desserts und Buffetangaben. Eine À-la-carte-Karte für herzhafte Gerichte und Sushi sowie eine Legende zur Kennzeichnung sind nachzutragen, sobald bestätigte Angaben vorliegen. Für Nr. 702 (Remy Martin Cognac, 0,04 l) steht in der Vorlage „550€“. Bis zur Klärung steht auf der Website „Preis bitte erfragen“.
